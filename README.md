 Agatha Profile Web Page

 Description

This project is a simple personal profile web page built using HTML. It presents basic information about the author, including educational background, personal interests, and career goals.

The purpose of this project is to demonstrate foundational web design skills and the ability to structure content clearly using HTML.



 Objectives

* To create a personal profile webpage
* To practice basic HTML structure and tags
* To present personal and academic information clearly
* To understand how web pages are organized



 Technologies Used

* HTML5 – for structuring the webpage



 Features

* Displays personal information (name, program, and bio)
* Explains motivation for studying web design
* Highlights career goals
* Simple and easy-to-read layout

---

 How to Run the Project

1. Download or clone the repository

   ```bash
   git clone https://github.com/your-username/agatha-profile.git
   ```

2. Open the project folder

3. Double-click the `index.html` file or open it in any web browser

 Usage

This webpage can be used as a basic personal profile or portfolio starter page. It is suitable for beginners learning web development.



 Rationale

This project was created to apply basic knowledge of HTML in building a structured webpage. It reflects an understanding of headings, paragraphs, and layout organization.
